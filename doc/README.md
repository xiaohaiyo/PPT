## 总体架构

```text
资料上传/知识库
       ↓
对话意图识别 ──→ 问答/摘要 ──→ RAG 引用回答
       │
       └──→ Creative Brief ──→ 生成任务
                                  ↓
                        产物类型对应的 Skill
                                  ↓
                         校验与确定性 Renderer
                                  ↓
                    PPTX / DOCX / SVG / PNG
```

左侧管理事实来源，中间对话负责分析和需求确认，右侧只管理生成记录与产物。
