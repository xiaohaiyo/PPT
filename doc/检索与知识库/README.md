# 检索与知识库

`backend/storage.py` 负责 PDF、DOCX、TXT 和 Markdown 的解析、持久化及检索。PDF 保留页码，DOCX 提取段落和表格；缺少文本层的扫描 PDF 会返回警告。

## 本地 RAG

```text
解析文本 → 按页/段落切分 → 限定用户选中范围
→ 中文二元词项与英文词项匹配 → 片段排序
→ 返回文档名、页码和原文引用
```

问答、摘要以及各类生成 Skill 共用该能力。没有命中证据时，问答不会把完整资料直接发送给模型，而是提示依据不足。

知识库是可复用的文档 ID 集合。用户可创建、重命名、调整成员或删除；本轮请求只使用已勾选资料与已选知识库的并集。

稀疏检索提供来源相关性，并将检索到的原文片段作为生成依据。
