# 前端模块

## 文件

- `app.html`：应用页面结构。
- `app.css`：基础布局与组件样式。
- `app-v2.css`：扩展组件、响应式和三栏独立滚动样式。
- `app.js`：页面状态、接口请求、对话、任务轮询和预览。

## 页面职责

- 左侧：上传资料、粘贴文本、勾选来源、管理知识库。
- 中间：问答、摘要、意图识别、Brief 确认和修改指令。
- 右侧：按类型显示任务、进度、预览、下载和修改入口。

上传和勾选不会自动调用模型。发送消息后，前端先请求 `/api/intent` 理解意图，再进入问答、摘要、需求整理或确认流程。中间对话区独立滚动，左右栏和输入框保持固定。

前端内存状态保存本轮选择、对话历史和当前 Brief；资料、任务及产物等持久化事实均以服务端为准。
